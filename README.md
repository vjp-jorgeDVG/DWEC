# DWEC

Repositorio de ejercicios de Desarrollo Web en Entorno Cliente.

## Sesión 6

La carpeta `retos-s6` contiene la tabla de veracidad y el calificador de notas. Para ejecutarlos, abre `retos-s6/retos.html` en el navegador y consulta la consola con F12.

## Sesión 7

La carpeta `retos-s7` contiene el reto 3 del carrito: el archivo con errores, la versión corregida y las explicaciones. Abre `retos-s7/retos_con_errores.html` para inspeccionar el original y `retos-s7/retos.html` para ejecutar la solución.

Los retos 1 y 2 de la sesión 7 están integrados en `js/app.js` del proyecto [Alimentación de Plasencia](https://github.com/vjp-jorgeDVG/alimentacion-plasencia), como indica la ficha.
